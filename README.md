# REC_ECBD_2026_Gonzalez_Ulises
Proyecto de evaluación de eficiencia energética de edificios con el dataset Energy Efficiency de UCI.

## Datos del estudiante

- Nombre: Ulises González Coronado
- Universidad: Universidad Tecnológica de Tula-Tepeji
- Programa: Desarrollo de Software Multiplataforma

## Descripción del proyecto

Este proyecto analiza las características de diferentes diseños de
edificios y su relación con las cargas de calefacción y refrigeración.
Se busca identificar patrones y desarrollar modelos que permitan
predecir estas cargas a partir de las características del edificio.

## Dataset

- Nombre: Energy Efficiency
- Fuente: UCI Machine Learning Repository
- Registros: 768
- Variables de entrada: 8
- Variables objetivo: Heating Load y Cooling Load
- Archivo original: data/raw/ENB2012_data.xlsx
- Enlace: https://archive.ics.uci.edu/dataset/242/energy+efficiency
